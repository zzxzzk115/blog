Basic Concepts

Lazy_V12/16/23About 1 min

Functions

A one-to-one mapping from the domain to the range:

f:R→Rf: \mathbb{R} \to \mathbb{R} f:R→R

Note

R\mathbb{R}R represents the one-dimensional real number domain.

Height Maps

A height map can be described as:

f:R2→Rf: \mathbb{R^2} \to \mathbb{R} f:R2→R

A height map is a 2D image where each pixel records a height value. It is commonly used to represent terrain.

2D Parametric Curve

f:R→R2f: \mathbb{R} \to \mathbb{R^2} f:R→R2

In other words: f(t)=pf(t) = pf(t)=p where ppp is a two-dimensional coordinate point (x, y).

3D Parametric Curve

f:R→R3f: \mathbb{R} \to \mathbb{R^3} f:R→R3

In other words: f(t)=pf(t) = pf(t)=p where ppp is a three-dimensional coordinate point (x, y, z).

Texture Mapping

The relationship mapping a texture to an object's surface can be described as:

f:Ω→R3f: \Omega \to \mathbb{R^3} f:Ω→R3

Here, Ω\OmegaΩ represents the texture domain (u, v), and R3\mathbb{R^3}R3 represents the spatial domain (x, y, z).
