# 数组 Array<!-- {docsify-ignore-all} -->

> 最简单的顺序存储结构

## 定义

**数组（array）**是一种线性表数据结构，它用一组连续的内存空间来存储一组具有相同类型的数据。

![array[4]](http://img.zhangkexuan.cn/markdown_20201111125157.png)

数组中元素的数据类型是一致的，计算机给数组分配内存的时候，根据所存类型计算需要的总空间。

例如上面的数组，需要存放5个int（整型）类型的元素，由于一个int类型的数据一般占4个字节，那么就需要5*4=20个字节。

!> 基本数据类型占的字节数和计算机操作系统位数有关，但在一般情况下，32位和64位计算机中的int都占4字节。以下是C/C++中基本数据类型在32位和64位机中所占字节数的图表：![c-type-byte-count](http://img.zhangkexuan.cn/markdown_20201111153513.png)



数组在内存中（物理中）是顺序存储的，从首地址开始，依次往后存储元素。

## 优缺点

数组的优点：

1. 定义简单，语法精简。
2. 可以随机访问，按照索引值寻找元素的时间复杂度是O(1)。

数组的缺点：

1. 元素类型只能是同一种。
2. 容量在定义时固定，不够灵活。
3. 插入删除元素时，需要一部分元素整体左移/右移，操作耗费时间。

## 指针和数组名的关系

国内老师可能都教错了，他们说数组名就是指针，这样的说法是错的，只能说对数组名取地址，得到的值和数组的首地址相等，这并不代表数组名就是一种指针。

数组名不是指针，也不一定是常量（根据C和C++的版本区别判断），但它可以隐性转换为指针。

```cpp
#include <iostream>

using namespace std;

int main()
{
	int a[] = {0, 1, 2, 3};
	int *p1 = a;
	int *p2 = &a[0];
	cout << sizeof(a) << endl;
	cout << sizeof(p1) << endl;
	cout << sizeof(p2) << endl;
	return 0;
} 
```

![test](http://img.zhangkexuan.cn/markdown_20201111162443.png)

如果说数组名就是指针（地址）的话，那么上面应该三行结果都相同，可是并不是。

因为数组类型和指针类型本身就不是同一种类型，sizeof对它们的处理方式也就截然不同。
