
# MyBlog

My personal blog, based on VuePress theme Hope.

## Getting Started

### 1. Install dependencies

```bash
pnpm install
# or
yarn install
# or
npm install
```

### 2. Start local development

```bash
pnpm docs:dev
# or
yarn docs:dev
# or
npm run docs:dev
```

### 3. Build static site

```bash
pnpm docs:build
# or
yarn docs:build
# or
npm run docs:build
```

### 4. Clean cache (if needed)

```bash
pnpm docs:clean-dev
# or
yarn docs:clean-dev
# or
npm run docs:clean-dev
```

### 5. Update theme & dependencies

```bash
pnpm docs:update-package
# or
yarn docs:update-package
# or
npm run docs:update-package
```
