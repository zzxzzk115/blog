问题：假定有三个数 a,b,c;我们要把他们按从小到大排序，要怎么做最简单？

<!--more-->

----

### 思路：

把最小的数放左边，最大的数放右边。可以用三个 if 实现排序。

----

### 实现：

三个 if 的方法：

```c
//_3if.c
int main(){
	int a,b,c,temp;
	//读入三个数
	scanf("%d %d %d",&a,&b,&c);
	//三个if 后续有列表解析过程
	if(a>b) temp=a,a=b,b=temp;
	if(b>c) temp=b,b=c,c=temp;
	if(a>b) temp=a,a=b,b=temp;
	//打印排序后的三个数
 	printf("%d %d %d",a,b,c);
	return 0;
}
```

----

## 列表过程：

| \ | a | b | c |
|--|--|--|--|
|第一组初值|3|1|2|
|第一个 if|1|3|2|
|第二个 if|1|2|3|
|第三个 if|1|2|3|
|第二组初值|7|6|5|
|第一个 if|6|7|5|
|第二个 if|6|5|7|
|第三个 if|5|6|7|
|第三组初值|1|2|3|
|第一个 if|1|2|3|
|第二个 if|1|2|3|
|第三个 if|1|2|3|

----

## 总结：

可见：三趟 if 可以使得三个数快速地进行排序，这是三个数排序最快最简单的方法，你理解了吗？
